# 🚀 Portfólio de Automação, IA e Integrações

Olá! Eu sou **Kauan Pires** 👋
Atuo na criação de **soluções comerciais reais usando automação, integrações e Inteligência Artificial**, com foco em **vendas, prospecção B2B, SDRs de IA e backend SaaS**.

Todos os projetos abaixo foram **desenvolvidos para uso prático em operações comerciais**, não são exemplos acadêmicos ou POCs. São fluxos pensados para **escala, conversão e eficiência operacional**, usando o **n8n como motor central**.

---

## 🧠 O que eu faço

* Transformo processos comerciais em **sistemas automatizados**
* Crio **SDRs de IA** que atendem, qualificam, prospectam e vendem
* Integro múltiplas ferramentas via **API e Webhooks**
* Uso IA de forma **estratégica**, orientada a resultado de negócio
* Estruturo **backends SaaS invisíveis**, prontos para produção

---
## 🧰 Tecnologias, Ferramentas e Stack 


| Categoria | Ferramentas |
|----------|-------------|
| Automação & Orquestração | n8n · Zapier · Pluga · Integrações via API REST · Webhooks (Inbound / Outbound) · HTTP APIs · Arquitetura orientada a eventos |
| CRM & Vendas | Pipedrive · PipeRun · Salesforce · Kommo CRM · Ramper (Pipeline · Prospect · Marketing) |
| Prospecção & Enriquecimento | Apollo.io · Snov.io · Apify · Dify (Actors) |
| Marketing & Comunicação | RD Station · Brevo · Lahar · Meeventos · Envio de e-mail via SMTP |
| Canais de Comunicação | WhatsApp (Evolution API · Umbler Talks) · Telefonia (Twilio) · Voz IA (ElevenLabs) |
| Inteligência Artificial & LLMs | OpenAI (ChatGPT) · DeepSeek · Gemini · Ernie · Perplexity · LangChain · Prompt Engineering |
| Machine Learning & Deep Learning | PyTorch · TensorFlow · PaddlePaddle |
| Dados, Estado & Persistência | Redis · Supabase (PostgreSQL) · Bancos SQL · Bancos NoSQL |
| Infraestrutura & DevOps | Docker · Docker Compose · Hospedagem · Manutenção de Servidores · Cloud Servers |
| Google Ecosystem | Google Workspace · Google Calendar · Google Meet · Google Sheets · Integrações com Google APIs |
